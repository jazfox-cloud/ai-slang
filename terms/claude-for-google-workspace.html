What does Claude for Google Workspace mean?

Claude for Google Workspace is Anthropic's add-on that puts a Claude sidebar inside Google Docs, Sheets, and Slides to work with the open file.

You work with Claude beside a document, spreadsheet, or presentation instead of copying its contents into a separate chat.

Origin and usage

Anthropic uses this product name for its Google Workspace integration. It names an application integration rather than a new Claude model.

Source type: product-term. Last checked: 2026-10-09.

Verified against Anthropic's product page and Help Center. The add-on is in beta; supported plans, browsers, and editing behavior may change.

Primary reference

One integration across three apps

One Marketplace installation covers Docs, Sheets, and Slides. The official page describes drafting documents, working with spreadsheet data, and creating or editing slides. Installation can depend on your organization's administrator.

Sidebar versus connector

The sidebar brings Claude into the file already open in Google Workspace. A connector brings external context or tools into Claude. These entry points have different access scopes; enabling a connector can extend what the assistant can reach.

Access and reviewing edits

By default, the add-on is restricted to the open file; enabled connectors can provide additional access. The Help Center documents an Ask before edits mode and restoring changes through version history. Review edits before relying on the result.

Examples

  • I opened Claude in Sheets and asked it to explain a formula before changing it.
  • The team reviewed Claude's proposed document edits inside Google Docs.

FAQ

Is this a new Claude model?

No. It is an integration that uses Claude models inside Google's office apps.

Can it automatically read my whole Drive?

Not through the add-on's default file access. Additional access depends on connectors you enable and their permissions.

Is it available to every Google account?

The checked documentation lists a beta for paid Claude plans. Google Workspace installation policies can also restrict access.
